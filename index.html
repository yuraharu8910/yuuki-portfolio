04 / HOW I WORK

想いが、形になり、 育っていくまで。

静かに育ち、最後に実る。
一つひとつの工程を、丁寧に。

  1. 01 HEAR

    想いを聞く

    まずは、サービスへの想いや、
    「誰に、何を届けたいのか」を丁寧に伺います。

    Interview / Hearing Sheet

  2. 02 RESEARCH

    知る・見つける

    ターゲットや競合を調べ、
    サービスならではの魅力や課題を整理します。

    Target / Persona / Competitor Research

  3. 03 DESIGN

    伝わる形を考える

    リサーチをもとに情報を整理し、
    デザイン・コンテンツ・導線を設計します。

    Structure / Wireframe / Visual

  4. 04 CREATE

    形にする

    設計した内容をもとに、
    Webサイト・LP・Reelsなど、
    目的に合った形へ落とし込みます。

    Web / LP / Reels

  5. 05 GROW

    育てる

    公開して終わりではなく、
    反応やデータを見ながら改善し、
    より届く形へ育てていきます。

    Analyze / Improve

想いを育て、実りにつなぐ。
