CLIENT WORK / CASE STUDY

La vie belle.mf

Web / LP / Chatbot

01

OVERVIEW

札幌のフェイシャルレメディ®サロン「La vie belle.mf」のLPに、AIチャットボットを組み込みました。初回体験を検討している人の「予約の前にちょっと聞きたい」にその場で答え、料金・施術時間・アクセスなどの疑問を解消して、予約や相談は公式LINEへスムーズにつなげることをねらっています。

GOAL
予約前の疑問にその場で答え、公式LINEでの予約・相談へつなげる
ROLE
ヒアリング、ロゴ制作、Instagram運用、チャットボットの設計・実装（画面・ナレッジ・バックエンド）、LPに合わせたチャット画面のデザインとコーディング、よくある質問のスプレッドシート設計、Google Apps ScriptによるClaude API連携、回答ルールの設計、公式LINEへの導線設計、利用状況の計測設定
TOOLS
VS Code / HTML / CSS / JavaScript / Google Apps Script / Google スプレッドシート / Claude（Claude API）/ Googleタグマネージャー

02

TARGET

LPを見て、初回体験の予約を考えている女性。予約の前に、料金や施術時間、メイクのまま行けるかなどを気軽に確かめたい人を想定しました。

03

DESIGN POINT

  • 3段階で確かめながら構築「画面のみ → スプレッドシートを参照するキーワード回答 → AI回答」の順に、段階ごとに動作を確認しながら作りました。
  • 書かれた範囲だけで答えるAIはスプレッドシートの情報の範囲だけで答え、書かれていないことや予約・空き状況の確認は公式LINEへ案内します。効果を言い切る回答もしないようにしています。
  • 止まらない・使いすぎない通信エラーや利用上限でAIが使えないときは、キーワード回答に自動で切り替わります。APIキーはGoogle Apps Script側だけに置き、1分・1日あたりの利用回数にも上限を設けました。
  • 運用しやすく、効果を測れる回答はスプレッドシートを更新するだけで差し替えられます。チャットを開いた回数・質問数・LINEへのクリック数も計測できるようにしました。
