PROJECT / CASE STUDY

とおまち夏花火ナイト

LP / Reels / Chatbot

01

OVERVIEW

地域の花火イベント「とおまち夏花火ナイト」のLP・リール・AIチャットボット。リールから訪れた人を観覧席の予約と宿のLINE相談へ案内し、来場前の疑問をその場で解消して離脱を減らすことを目指しました。

GOAL
リールからの流入を、観覧席の予約・宿のLINE相談へつなげる／来場前の疑問をその場で解消する
ROLE
キャラクター「とおま」のAI画像生成、AI動画生成、LP制作一式、AIチャットボットの設計・実装、ナレッジ設計
TOOLS
Figma / Photoshop / AI画像生成 / AI動画生成 / Claude（Claude API）/ Google スプレッドシート / Railway / VS Code / HTML・CSS・JavaScript

02

TARGET

週末のデートで出かける、20代後半〜30代の会社員女性を想定しました。

03

DESIGN POINT

  • キャラクターと映像をすべてAIで生成案内役のキャラクター「とおま」、画像、背景動画をAIで生成しました。チャットを開くボタンにも、動く「とおま」を使っています。
  • チャットボットを3段階で構築見た目の画面から始め、スプレッドシートのルールで答える段階、Claude APIで答える段階へと順に作り込みました。
  • 答えの正確さと安全性Claude APIはナレッジに書かれた範囲だけで答えるようにし、事実と違う回答を防いでいます。APIキーはバックエンド（Railway）だけが持ち、ページ側には出しません。
  • チャットから行動へチャットの中から、観覧席の予約とLINE相談へそのまま進めるようにしました。
